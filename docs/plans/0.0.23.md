# 0.0.23 plan: rs-rich-doom's core gaps and `rich-rst` 2.2.0

**Status:** started on 2026-10-25 as a list of what [0.0.22](0.0.22.md)
handed on. It is filled in once 0.0.22's cohort is tagged; 0.0.22 was
published the same day, and the versions are open (see
[Package impact](#package-impact)). It belongs to
stage 2 of the [plan to 1.0.0](1.0.0.md).

## Handed on from 0.0.22

Both were the maintainer's call on 2026-10-25.

### 1. rs-rich-doom's core gaps: art, intuituive, record

rs-rich-doom, rebuilt on the 0.0.21 crates, lists what it still builds for
itself in [its core gaps](../design/doom-core-gaps.md). Each is generic:
each names a use other than Doom, and nothing of Doom's (WAD, DMX, MUS,
OPL, its keys) goes into core. Gap 4, made-up releases with a first-press
hold and a repeat hold, lands in 0.0.22.

- **Pictures:** a live frame image node in intuiTUIve's `art` plugin
  (gap 1); a public Sixel encoder for indices and a palette (gap 2) and
  Kitty raw-pixel transmission (gap 3) in rs-rich-art.
- **The clock and stats:** a worker that steps in lockstep with the app's
  clock (gap 5) and draw timings in `FrameStats` (gap 6).
- **Audio:** a voice mixer for effects (gap 7), a render-callback output
  for synthesizers (gap 8), a paced test sink and capture (gap 9), and
  ALSA's messages kept off the screen for the stream's life (gap 10).
- **Pixels:** a palette-keeping two-colour rule for Braille and quadrants
  (gap 11) and an aspect-fitted pixel buffer (gap 12).
- **Recordings:** sound in `rich record` tapes (gap 13).

Each gap's entry has its proposed API and acceptance tests. When one
lands, rs-rich-doom drops its own version of it.

### 2. `rich-rst` 2.2.0: cli

Move the `rich-rst` pin in [`UPSTREAM.toml`](https://github.com/buchochelliq-labs/rs-rich-cli/blob/main/UPSTREAM.toml)
from 1.3.2 to 2.2.0 (the [plan to 1.0.0](1.0.0.md#track-a-parity) names
it), and port `rich --rst` to it with fresh goldens.

### 3. Memo's illustrations: docs

0.0.22 ships the cartoon crate spots as hand-written SVG. The maintainer
wants them closer to their own reference pictures (made with an AI image
tool) and will revisit the art; the flat SVGs stay as the icon tier
either way. Noctiluca's "Memo amazed" stays in the flat style until then.

## Package impact

Against the 0.0.22 cohort's versions (published 2026-10-25). The versions
are open: every package moved one patch past 0.0.22, in the commit after
0.0.22's publication notes (the commit `docs-versions.toml` names for
0.0.22's docs). Cargo's 0.0.x requirements are exact, so a crate that
depends on one that moves moves too. The reasons are filled in with the
workstreams.
