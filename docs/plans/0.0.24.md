### lumis 0.17: lumis

no code change, but raises lumis's minimum Rust from 1.91 to 1.95, so
rs-rich-lumis's `rust-version` and the CLI's and the Python package's

`claude/next-priority-items-3c5p8e-wip-deps-023-lumis`; it was not checked
on 1.95 itself. No tape or guide screenshot is highlighted by lumis.
