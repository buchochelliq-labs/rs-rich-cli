# 0.0.7 development plan

The 0.0.7 CLI workstream adds watch mode as a binary-boundary convenience. It
does not change the faithful `rich` renderer or introduce a second core refresh
system.

## Watch scope

- Poll local files on a configurable interval without a busy loop.
- Treat atomic-save gaps and parse failures as recoverable frames.
- Poll URLs only when the existing `fetch` feature is enabled; optionally hash
  fetched responses to suppress unchanged frames.
- Render one snapshot and exit when stdout is redirected.

The implementation reuses the existing parser, decorators, exporters and
one-shot render path. Its status is recorded in `docs/PORTING.md` because this
is intentionally a CLI-only divergence from upstream `rich-cli`.

## Confidence tooling

This workstream is deliberately bounded to regression confidence for the
selected CLI surfaces. It does not introduce a RenderTarget abstraction or a
general fuzzing service.

| Issue | Completed here | Deferred |
|---|---|---|
| #150/#135 | Deterministic CLI snapshot runner with width/profile injection, terminal PTY execution for color profiles, option-terminator (`--`) positioning, stable environment, normalized output, and unified failure diffs. | Batch/profile/watch/image snapshots until their command contracts are stable. |
| #34 | Differential corpus and generator extended with box renderables (`Panel` box variations) and deterministic safe-box capability profiles; replay remains seed-based. | Differential generation for future CLI subcommands and unbounded fuzzing. |
| #35 | Library benchmark width/color controls and artifact metadata. | CI timing thresholds, artifact retention policy, and cross-host performance claims. |

Run the focused checks with:

```bash
python -m unittest scripts/test_snapshot_cli.py scripts/test_diff_rich.py
cargo test -p rs-rich --example library_bench
```

The snapshot runner's capability profiles are explicit inputs. It does not
inspect the developer terminal, and missing or changed snapshots fail with a
bounded unified diff rather than silently rewriting files.
