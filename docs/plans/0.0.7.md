# 0.0.7 development plan

The 0.0.7 CLI workstream adds watch mode as a binary-boundary convenience. It
does not change the faithful `rich` renderer or introduce a second core refresh
system.

## Watch scope

- Poll local files on a configurable interval without a busy loop.
- Treat atomic-save gaps and parse failures as recoverable frames.
- Poll URLs only when the existing `fetch` feature is enabled; optionally hash
  fetched responses to suppress unchanged frames.
- Render one snapshot and exit when stdout is redirected.

The implementation reuses the existing parser, decorators, exporters and
one-shot render path. Its status is recorded in `docs/PORTING.md` because this
is intentionally a CLI-only divergence from upstream `rich-cli`.
