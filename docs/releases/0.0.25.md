# 0.0.25 cohort: the two tracks' last release, and the first on rab

![Memo, intuiTUIve's elephant, in the cartoon look](../assets/intuituive/mascot/memo-cartoon.svg){ .tui-mascot width="128" }
**To be published** by one release run, `release-0.0.25`, with `rs-rich`
0.0.13 on PyPI. See [Publication](#publication).

0.0.25 is the last release before 0.1.0, the API review
([the 1.0.0 plan](../plans/1.0.0.md), decision 15): it closes the two
tracks 0.0.24 opened, and what of them is not ready moves on, named below.
It landed in one wave of parallel work (#847 to #850). The
[0.0.25 plan](../plans/0.0.25.md) has every item and what moves on.

- **Cornacai, phase 4.** It gains:
  - a session store, and resume with `session/load` when the agent offers
    it (Ctrl+O, `--resume ID`, `--sessions`);
  - sign-in: when the agent asks, its advertised methods are offered and
    `authenticate` is called with the one picked;
  - agent terminals on a PTY, behind `--pty` or `[terminal] pty = true`,
    falling back to pipes;
  - agents from the marketplace: the new `agent` listing kind, recorded
    (never run) by `rich plugin install`, offered after the built-in ones.

  See [Cornacai](../guide/cornacai.md).
- **intuiTUIve finishes Textual parity's named gaps.** It gains:
  - #812's last stylesheet properties: `offset`, `opacity`, `tint`,
    `outline`, `hatch`, `keyline`, `scrollbar-color-hover` and
    `scrollbar-size`;
  - `DataTable` row labels and cells holding any renderable;
  - separators in an option list;
  - highlighting in a `text_area` that carries the state of the lines
    above its view (a block comment opened above it);
  - new generic widgets: `dial`, `rating`, `rating_input` and `carousel`.

  [The parity audit](../design/textual-parity.md) tracks what is left.
- **Noctiluca on real sites, second pass**
  ([the design](../design/noctiluca-real-sites-2.md)), sixteen generic
  fixes, none naming a site:
  - canvases are drawn and inline SVGs captured again while they change,
    so a speed test's gauge moves;
  - meters, progress bars and star ratings are native controls, drawn with
    intuiTUIve's bar, dial and rating;
  - fixed and sticky layers: top bars pinned, cookie and sign-up bars
    docked; paint order, and badges over pictures;
  - sideways shelves page as a strip, `‹ 1–3 of 6 ›`;
  - prices read as their screen-reader text, icon-only buttons get a
    face, right-edge controls shorten instead of being cut, lazy
    thumbnails get a placeholder;
  - a failed navigation keeps the address you asked for.
- **Named pipes on Windows.** rs-rich-ext's new `local_socket` (behind
  `local-socket`) is a socket private to one user, a Unix domain socket on
  Unix and a named pipe on Windows; rs-rich-interact's control socket
  (Noctiluca's `--control`) and `rich console` use it, so both work on
  Windows.
- **Releases run on rab**, the Release Asset Bundle (formerly
  release-kit), v2.0.0: one `release.yml` run publishes crates.io and PyPI,
  tagged with `python3 .github/rab/scripts/release.py tag`, and every run
  leaves a release record. This is its first release.
- **The API review's groundwork:** every public item documented, with
  `#![warn(missing_docs)]` on, in ten stable crates; the other five's
  counts and an inventory of every foreign type in the stable set's public
  APIs are in [the API review's groundwork](../design/api-review.md).
- **Fixed:** a stylesheet could take seconds and gigabytes to parse (the
  fuzz finding of 2026-11-03); parsing is now linear in its length.

A default build of `rs-rich` still renders exactly like upstream `rich`
15.0.0.

## Migration

Breaking changes in 0.0.x crates (the
[CHANGELOG](https://github.com/buchochelliq-labs/rs-rich-cli/blob/main/CHANGELOG.md)
has each, and `api/semver-breaks.toml` lists them with their reasons):

- **noctiluca:** `Media`, `Run`, `Control`, `Page`, `Block` and
  `Projection` gain fields (live regions, twins, glyphs, hover-only
  controls, placeholders, indicators, layers, shelves); `BlockKind`,
  `Rule`, `PageAction` and `Command` gain variants;
  `noctiluca::control::unix_only` is gone, since the control socket works
  on Windows.
- **rs-rich-intuituive:** `TableOptions` gains `row_labels` and
  `renderables`. A stylesheet nested more than 32 deep, or one whose
  nesting or variables expand it past its bound, is now an error.
- **cornacai:** `Options` gains `pty`, `store` and `resume`; `Config`
  gains `pty`.
- **The marketplace:** a search leaves out, with a warning, a listing of
  a kind or format this release does not know, rather than failing.

  Results: see the release PR.

  walked by hand, and one Cornacai run with a real agent, both noted here.

### Not in this release

These move to 0.1.0 or later (the plan's decision 1):

- **Stylesheets:** state-driven properties (`opacity`, `tint`, `outline`,
  `hatch`, `offset` and the scrollbar's size follow a node's kind, name and
  fixed classes, not `:hover` or `:focus`); the `:inline` and
  `:first-of-type` pseudo-classes; Textual's `layer`s and the rest of its
  long tail; an `offset` past the screen's left or top edge stops there
  rather than being clipped.
- **Cornacai:** an agent terminal drawn live as a terminal in its card,
  sending the shell pane's selection, and terminal sign-in methods.
- **`missing_docs`** for the five crates not yet at zero: noctiluca,
  rs-rich-intuituive, rs-rich-interact, rs-rich-ext, and core once the
  review decides how.
- **Noctiluca:** Shift+wheel and clicks on a shelf's `‹ ›`, folding a
  page's own Previous and Next buttons into the strip, the real-site
  pictures recorded again, and a live look at Google, speedtest.net and
  Amazon (covered by fixtures only) and at YouTube's and Twitch's rows.
- **lumis 0.17** waits: it raises rs-rich-lumis's minimum Rust to 1.95.
- **Memo's illustrations** wait for the maintainer's reference pictures.
- **#791** (Noctiluca) needs a residential network.
