# Borrowed Screen graphics discovery

Continuation of the [approved media-quality design](2026-11-08-noctiluca-media-quality-design.md), following [ordinary metadata transport](2026-11-08-screen-metadata-transport-design.md). The single current bound diagnostic recorded 18.755ms exporting composed Screen cells to owned Segments and 20.155ms building another Frame over 86 paints; rectangle scanning took 4.695ms. These are diagnostic aggregate wall times, not promised CPU savings.

The shared Driver should offer its already-composed Screen directly to graphics sources. An additive provided `PlacementSource::placements_from_screen(&self, screen: &Screen, cell_pixels: Option<(u16, u16)>) -> Vec<Placement>` preserves third-party implementors through a default adapter that performs exactly the old Screen-to-Segments-to-Frame route and calls `placements_with_metrics`. Existing Frame APIs and explicit manual painters continue to work unchanged.

The stock optional image source overrides this method with borrowed cell/style discovery. It must share one rectangle/placement algorithm with the Frame route and preserve its exact grouping semantics, source coordinates, instance separation, crop geometry, limits and resource ownership. Only surviving composed cells count; layout rectangles do not prove visibility. Unknown/legacy provenance remains supported. In particular, legacy metadata may rely on a full-width equal-style run, so treating each cell as a new legacy source origin is incorrect.

Screen styles may be borrowed for the duration of one call. No persistent StyleId cache, retained reference, full style-table clone or copied private image-tag parser is permitted. A bundled provenance decoder is not needed for this scope: the measured parser/rectangle cost is small relative to transport. Do not introduce an attachment plane, new public fields, a browser-specific fast path or changes to rich-art tag wire formats.

Parity is defined by comparing Frame-derived and borrowed-Screen-derived placements and decoded drawing output for the same composed scene, including partial columns/rows, holes, overlapping layers, adjacent/translated copies, full and fragmented legacy tags, bound tags, Kitty/iTerm/Sixel and known/unknown cell metrics. Same geometry alone is insufficient: compare source crops, graphic keys/frame identities, decoded colors and retirement/output-written ordering. The old reference and default trait adapter must remain independently usable by an external public consumer.

Keep the change only with identical behavior and reduced export/build work in one frozen component comparison. Original application quality, baseline, offers, populations and gates remain fixed; a later declared application sequence determines release readiness. Native-terminal validation remains distinct from escape-byte/placement correctness. No push, merge or publication is authorised.
