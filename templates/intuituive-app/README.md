# {{project-name}}

An [intuiTUIve](https://github.com/buchochelliq-labs/rs-rich-cli/tree/main/docs/guide/intuituive)
terminal app.

```bash
cargo run                         # run it
INTUITUIVE_INSPECT=1 cargo run    # with the inspector docked on the right (F12 toggles it)
cargo test                        # its tests, run headless
```

Edit `theme.ini` while the app runs: it redraws in the new styles.

The [tutorial](https://github.com/buchochelliq-labs/rs-rich-cli/blob/main/docs/guide/intuituive/tutorial.md)
builds a to-do app from here, one step at a time.
